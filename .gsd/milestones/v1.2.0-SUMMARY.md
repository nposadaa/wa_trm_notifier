## Key Decisions (This Milestone)

- **DEC-031**: Mandatory release protocol checklist (README + VERSION + CHANGELOG)

- **DEC-034**: Deep clean must never delete Service Worker or IndexedDB

## Lessons Learned
- GCP e2-micro VMs introduce significant WebSocket latency; polling windows must be generous (10+ min for checkmark verification)
- WhatsApp Web's Service Worker and IndexedDB are critical infrastructure — cleaning them causes unrecoverable session crashes
- Exponential backoff on the Socrata API scraper absorbs transient 502/503 errors that were causing premature alerts
- Deduplication guards prevent duplicate broadcasts when fallback cron jobs run after a timed-out verification
- The Playwright session decryption sync can stall on resource-constrained VMs; reload-based self-healing is more resilient than hard abort
